Aetheria Online Client

โปรแกรมสำหรับเล่น Aetheria Online บน Windows 64-bit พร้อมโหมด Picture-in-Picture และคีย์ลัดควบคุมหน้าต่าง

ดาวน์โหลด

ดาวน์โหลดโปรแกรมได้ที่หน้า Releases

เปิดรุ่นที่ต้องการ แล้วเลือกไฟล์ดาวน์โหลดในส่วน Assets

Setup (.exe): เปิดตัวติดตั้ง เลือกโฟลเดอร์ แล้วติดตั้ง โปรแกรมจะสร้าง Shortcut บนเดสก์ท็อปให้
แบบ Portable (.exe): โหลดไฟล์แล้วดับเบิลคลิกเปิด Aetheria Online.exe ได้เลยโดยไม่ต้องติดตั้ง
คีย์ลัด
ปุ่ม	การใช้งาน
F5	รีเฟรชเกม
Ctrl+Shift+P	สลับ PiP / จอปกติ
F11 / Alt+Enter	สลับเต็มหน้าจอ
Esc	ออกจากเต็มหน้าจอหรือกลับจาก PiP
F1 / Ctrl+,	เปิด / ปิดวิธีใช้และการตั้งค่า
F8	ซ่อนเกมและปิดเสียง
Ctrl+Shift+H	ซ่อน / เรียกเกมกลับ

ดับเบิลคลิกไอคอนเกมในถาดระบบเพื่อเรียกกลับได้เช่นกัน

แถบควบคุม (Control Bar)
⟳ : รีเฟรชเกม (F5)
⧉ : โหมด Picture-in-Picture ย่อเล็กได้ถึง 64×48 พิกเซล (Ctrl+Shift+P)
⛶ : สลับโหมดเต็มหน้าจอ (F11 / Alt+Enter)
🔊 / 🔇 : เปิด / ปิดเสียงเกม
👁 : ซ่อนเกมและปิดเสียงลงถาดระบบ (F8)
⚙ : เปิดการตั้งค่าไคลเอนต์ เช่น ภาษา (TH/EN) และปรับแต่งสีธีม (F1 / Ctrl+,)
หมายเหตุ
ต้องใช้อินเทอร์เน็ตเพื่อเชื่อมต่อเกม
รองรับระบบปฏิบัติการ Windows 10 / Windows 11 (64-bit)
รองรับการลงชื่อเข้าใช้ด้วย Google (Google Sign-In) ผ่านเบราว์เซอร์อย่างปลอดภัย
การกด F8 (ซ่อนเกมลงถาดระบบ) ตัวเกมจะยังคงทำงานเบื้องหลัง 100% ตัวละครยังคงเดิน ตีมอนสเตอร์ และฟาร์มเลเวลได้ตามปกติโดยไม่หยุดพัก
ในโหมดเต็มหน้าจอ แถบควบคุมด้านบนจะซ่อนตัวอัตโนมัติ (เลื่อนเมาส์ไปชิดขอบบนของจอเพื่อแสดงแถบควบคุม)
