## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

- [x] **🖼️ โหมด Picture-in-Picture (PiP):** ย่อจอเกมให้ลอยอยู่เหนือหน้าต่างอื่นเสมอ และสามารถปรับย่อขนาดได้เล็กสุดถึง **64×48 พิกเซล**
- [x] **👁️ โหมดซ่อนเกมเบื้องหลัง (Boss Key - F8):** ซ่อนหน้าต่างลงถาดระบบ (System Tray) พร้อมตัดเสียงทันที โดย **ตัวเกมยังคงรันประมวลผล ตีมอนสเตอร์ และฟาร์มเลเวล 100% เบื้องหลัง** ไม่ตัดการเชื่อมต่อ
- [x] **🔑 เข้าสู่ระบบด้วย Google อย่างปลอดภัย:** รองรับ Google Sign-In ผ่าน Official Desktop Protocol โดยเชื่อมต่อกับเบราว์เซอร์ภายนอกอย่างถูกต้อง
- [x] **🎨 แถบควบคุมธีมน้ำเงิน-ทอง (Royal Navy & Gold):** ปรับแต่งโทนสีแถบควบคุมได้ 4 สไตล์ (Royal Navy, Sapphire, Void Gold, Astral Blue) หรือเลือกผสมสีด้วย Color Picker
- [x] **🌐 รองรับ 2 ภาษา:** สลับใช้งานภาษาไทย (TH) และ English (EN) ได้ทันทีจากเมนูตั้งค่า
- [x] **🔄 ฟังก์ชันดึงหน้าต่างอัจฉริยะ:** ป้องกันพิกัดหลุดออกนอกจอ และดึงหน้าต่างเกมกลับมาแสดงผลด้านหน้าสุดอัตโนมัติเมื่อล็อกอินเสร็จ

## ⌨️ ตารางคีย์ลัด (Keyboard Shortcuts)

| คีย์ลัด (Shortcuts) | ฟังก์ชันการทำงาน |
| :--- | :--- |
| <kbd>F5</kbd> | รีเฟรชหน้าเกม (ใช้ได้แม้ขณะเล่นในโหมดเต็มหน้าจอ) |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | สลับโหมด **Picture-in-Picture (PiP)** / จอปกติ (ย่อได้ถึง **64×48 px**) |
| <kbd>F11</kbd> หรือ <kbd>Alt</kbd> + <kbd>Enter</kbd> | สลับโหมด **เต็มหน้าจอ (Fullscreen)** |
| <kbd>Esc</kbd> | ออกจากโหมดเต็มหน้าจอ หรือออกจากโหมด PiP สู่จอปกติ |
| <kbd>F1</kbd> หรือ <kbd>Ctrl</kbd> + <kbd>,</kbd> | เปิด / ปิด หน้าต่างวิธีใช้และการตั้งค่าไคลเอนต์ (Settings) |
| <kbd>F8</kbd> | ซ่อนเกมลงถาดระบบ (System Tray) พร้อมปิดเสียง (Boss Key) |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> | คีย์ลัดสากลสำหรับ **ซ่อน / เรียกหน้าต่างเกมกลับคืนมา** (Global Hotkey) |

> [!NOTE]
> เมื่อซ่อนเกมลงถาดระบบ สามารถดับเบิลคลิกที่ไอคอน **Aetheria Online** บริเวณมุมล่างขวาของ Taskbar เพื่อเรียกเกมกลับขึ้นมาได้เช่นกัน

## 🎛️ ปุ่มบนแถบควบคุม (Control Bar)

แถบควบคุมด้านบนออกแบบมาให้ใช้งานสะดวก และจะซ่อนอัตโนมัติเมื่ออยู่ในโหมดเต็มหน้าจอ (เลื่อนเมาส์ชิดขอบบนเพื่อแสดงผล):

| ปุ่ม | ชื่อปุ่ม | คำอธิบาย |
| :---: | :--- | :--- |
| **`⟳`** | รีเฟรชเกม | โหลดหน้าเกมใหม่ (`F5`) |
| **`⧉`** | โหมด PiP | สลับหน้าต่างให้ลอยอยู่บนสุดและย่อขนาดได้อิสระ (`Ctrl+Shift+P`) |
| **`⛶`** | เต็มหน้าจอ | ขยายหน้าจอเต็มพื้นที่ตัดขอบหน้าต่าง (`F11`) |
| **`🔊 / 🔇`** | ปิด/เปิดเสียง | สลับเปิดหรือปิดเสียง BGM/SFX ทั้งหมดของเกม |
| **`👁`** | Boss Key | ซ่อนเกมและตัดเสียงลง System Tray (`F8`) |
| **`⚙`** | การตั้งค่า | เปิดหน้าต่างตั้งค่าภาษา, สีแถบควบคุม และสร้างทางลัด (`F1` / `Ctrl+,`) |

## ⚙️ ระบบการรันเบื้องหลัง (Background Farming Support)

โปรแกรมได้รับการปรับแต่ง Engine Flags เพื่อรองรับการเล่นเกม MMORPG บนเว็บโดยเฉพาะ:
* **ปิด Background Throttling:** ตัวเกมไม่ถูกลดรอบการทำงาน (Maintain 60 FPS Engine Logic) แม้จะกดซ่อนหน้าต่างด้วย <kbd>F8</kbd>
* **ล็อกสถานะ Visibility:** ป้องกันไม่ให้เอนจินของเกมเข้าสู่โหมดพัก (Pause Mode)
* ทำให้คุณสามารถเปิดตัวละครทิ้งไว้เพื่อ **ตีมอนสเตอร์ ฟาร์มไอเทม หรือตั้งร้านค้า** ได้อย่างต่อเนื่องโดยไม่ต้องเปิดหน้าต่างทิ้งไว้ให้เกะกะสายตา
